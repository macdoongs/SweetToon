# Demo cover artwork

These covers were generated specifically for the fictional SweetToon demo
series with Codex built-in image generation on 2026-07-25. They are original
demo assets, not thumbnails copied from commercial manga or Komga libraries.

- `moonlight-laundry.webp`: healing fantasy, a moonlit memory laundry
- `corner-store.webp`: quiet late-night convenience-store stories
- `neon-blade.webp`: an original cyberpunk swordsman in future Seoul
- `rooftop-garden.webp`: an adult office romance in a rooftop garden
- `catalog-01.webp`: a magical coastal post office in heavy rain
- `catalog-02.webp`: a child collecting fallen stars above the city
- `catalog-03.webp`: an after-work magical shop in a Seoul alley
