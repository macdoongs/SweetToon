# Demo cover artwork

These four covers were generated specifically for the fictional SweetToon demo
series with Codex image generation on 2026-07-25. They are original demo assets,
not thumbnails copied from commercial manga or Komga libraries.

- `moonlight-laundry.webp`: healing fantasy, a moonlit memory laundry
- `corner-store.webp`: quiet late-night convenience-store stories
- `neon-blade.webp`: an original cyberpunk swordsman in future Seoul
- `rooftop-garden.webp`: an adult office romance in a rooftop garden

All covers intentionally contain no generated title text. The application
renders accessible series titles and metadata as HTML.
