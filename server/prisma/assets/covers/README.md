# Demo cover artwork

These covers were generated specifically for the fictional SweetToon demo
series with Codex built-in image generation on 2026-07-25. They are original
demo assets, not thumbnails copied from commercial manga or Komga libraries.

- `moonlight-laundry.webp`: healing fantasy, a moonlit memory laundry
- `corner-store.webp`: quiet late-night convenience-store stories
- `neon-blade.webp`: an original cyberpunk swordsman in future Seoul
- `rooftop-garden.webp`: an adult office romance in a rooftop garden
- `catalog-01.webp`: a magical coastal post office in heavy rain
- `catalog-04.webp`: an everyday neighborhood hero carrying groceries
- `catalog-07.webp`: an intimate late-night kitchen conversation
- `catalog-10.webp`: an impossible blue pedestrian signal in the rain
- `catalog-13.webp`: a gentle monster navigating office life
- `catalog-16.webp`: a photographer and a supernatural developed image
- `catalog-19.webp`: a courier delivering a parcel to a tiny magical doorway
- `catalog-22.webp`: an old Seoul alley divided between past and future

All covers are normalized to 600×840 WebP and intentionally contain no
generated title text. The application renders accessible series titles and
metadata as HTML.
