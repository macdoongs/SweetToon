# SweetToon PR 리뷰 체크리스트

과제 심사 기준과 SweetToon의 실제 실패 가능성을 함께 확인한다. 모든 항목이
모든 PR에 적용되는 것은 아니며, 적용되지 않는 항목은 이유를 남긴다.

## 사용자와 범위

- [ ] 이 변경의 주 사용자가 독자, 창작자, 운영자 중 누구인지 명확하다.
- [ ] 사용자의 시작점, 성공 지점, 다음 행동이 화면에서 이어진다.
- [ ] 로딩, 빈 상태, 오류, 성공 피드백이 사용자 언어로 표현된다.
- [ ] 로그인이나 외부 계정 없이 심사자가 핵심 흐름을 확인할 수 있다.
- [ ] 미완성 기능은 작동하는 것처럼 보이지 않고 범위가 명확히 안내된다.

## API와 도메인

- [ ] 입력과 응답 경계가 Zod 또는 동등한 계약으로 검증된다.
- [ ] 오류 응답에 안정적인 `code`와 한국어 `message`가 있다.
- [ ] route에 비즈니스 규칙과 Prisma 세부 구현이 과도하게 섞이지 않는다.
- [ ] repository/provider 인터페이스를 테스트 대역으로 교체할 수 있다.
- [ ] URL path segment가 안전하게 인코딩된다.
- [ ] `api.sweetbook.com`이나 실제 인쇄 API를 호출하지 않는다.
- [ ] 인쇄 흐름은 `PrintProvider`를 통하고 mock 이외 설정은 거부된다.

## 데이터와 마이그레이션

- [ ] migration이 기존 데이터를 삭제하거나 의미 없이 초기화하지 않는다.
- [ ] 백필, unique 제약, nullable 전환 순서가 기존 DB에서도 안전하다.
- [ ] 시드를 여러 번 실행해도 사용자·주문 데이터가 보존된다.
- [ ] 빈 DB와 기존 DB에서 모두 기동 가능하다.
- [ ] 목록 집계와 정렬이 데이터 증가 시 명백한 병목을 만들지 않는다.

## 웹과 접근성

- [ ] 핵심 콘텐츠가 초기 HTML 또는 명시적인 로딩 상태로 제공된다.
- [ ] 페이지별 제목, heading 계층, breadcrumb/내비게이션 역할이 명확하다.
- [ ] 키보드 focus와 링크·버튼의 의미가 구분된다.
- [ ] 동적 내비게이션은 URL, 제목, 화면 데이터가 함께 변경되는지 확인했다.
- [ ] 모바일 폭에서 잘림, 겹침, 과도한 고정 요소가 없다.
- [ ] 이미지에 의미 있는 alt가 있고 장식 이미지는 접근성 트리에서 제외된다.

## 레이아웃과 시각적 일관성

- [ ] 일반 페이지의 인접한 주요 섹션이 같은 `--content` 폭과 좌우 여백을 쓴다.
- [ ] full-bleed 영역은 의도된 리더·히어로에 한정되고 관리 폼이나 목록이 화면
      가장자리에 붙지 않는다.
- [ ] 비교·관리 목적의 목록은 세로 목록 또는 반응형 그리드이며, 가로 레일은
      탐색·추천 목적에만 사용한다.
- [ ] 회차 번호·순번이 데이터와 HTML list marker에서 이중으로 표시되지 않는다.
- [ ] 배경·본문·보조 문구가 의미 색상 토큰을 사용하고 라이트·다크 테마 모두에서
      읽을 수 있다.
- [ ] `sticky`·`fixed` 도구가 스크롤 중 콘텐츠 위에 불필요하게 남지 않으며,
      포인터 선택 후와 키보드 `:focus-visible` 동작이 구분된다.
- [ ] 페이지 이동 뒤 URL·내용뿐 아니라 스크롤 위치와 열린 도구 상태도 올바르게
      초기화 또는 보존된다.

## SEO와 공개 콘텐츠

- [ ] 검색 대상 페이지에 title, description, canonical이 있다.
- [ ] Open Graph/Twitter Card 이미지가 외부에서 접근 가능한 래스터 형식이다.
- [ ] JSON-LD의 사용자·작가 입력이 안전하게 직렬화된다.
- [ ] 없는 콘텐츠와 오류 페이지는 index되지 않는다.
- [ ] `robots.txt`와 `sitemap.xml`이 배포 환경 기준 URL을 반환한다.

## ZIP/CBZ 업로드

- [ ] zip-slip과 절대경로 항목을 차단한다.
- [ ] 업로드 크기, 항목 수, 압축 해제 총용량 제한이 있다.
- [ ] PNG/JPEG/WebP만 허용하고 SVG 및 실행 가능한 콘텐츠를 거부한다.
- [ ] MIME signature와 확장자를 함께 검증한다.
- [ ] `1, 2, 10` 순서의 natural sort와 사용자의 순서 확인 단계가 있다.
- [ ] 실패한 업로드가 고아 파일이나 불완전 DB 행을 남기지 않는다.

## 보안과 운영

- [ ] 비밀정보, credential, 개인 경로, 고정 사설 IP가 커밋되지 않았다.
- [ ] 포트와 환경별 호스트가 환경변수로 변경 가능하다.
- [ ] 운영 컨테이너에 적절한 restart와 healthcheck가 있다.
- [ ] CI가 검증한 Git SHA만 배포할 수 있다.
- [ ] 공개 저장소의 CI/CD 파일이 개인 인프라 없이는 심사 실행을 방해하지 않는다.
