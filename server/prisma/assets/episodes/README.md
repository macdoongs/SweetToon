# Demo episode artwork

The eight images in `moonlight-laundry/s1e1` were generated specifically for
SweetToon's fictional showcase episode, "맡겨진 얼룩", with Codex image
generation on 2026-07-25.

They form one original healing-fantasy sequence and are not copied from a
commercial webtoon, manga archive, or Komga library. Generated PNG originals
are retained outside the repository; these checked-in WebP derivatives are
resized to 1,200px width for the web reader.

The panels intentionally contain no speech bubbles or generated text. Episode
titles, navigation, and accessible labels remain semantic HTML in the
application.
